Tonique vs Fondamentale
-- Tonique — centre harmonique de la gamme
La tonique est un concept harmonique : c'est la note de repos de ta tonalite, definie par le contexte musical.
La fondamentale est un concept acoustique : c'est la frequence physique la plus basse d'un son, mesurable dans SPAN, independante de tout contexte.

Quand ta basse joue la tonique, les deux coincident. Quand elle joue le V degre (--), la fondamentale est -- mais la tonique du morceau reste --. Ton kick peut avoir une fondamentale a 55 Hz (A1) dans un morceau en -- — les deux sont independants.

Comprendre le cercle
Gamme relative
Deux tonalites sont relatives quand elles partagent exactement les 7 memes notes, avec une tonique differente.

Ex : D mineur et F majeur = D E F G A Bb C dans les deux cas.

La relative majeure = tonique + 3 demi-tons. Transition invisible, aucun accord pivot necessaire.
Gamme parallele
Deux tonalites sont paralleles quand elles ont la meme tonique mais un mode different.

Ex : D mineur et D majeur = meme note D, mais D majeur a F# et C# au lieu de F et C.

3 notes changent entre majeur et mineur naturel. Meme tonique, couleur radicalement differente.
Modulation par quintes
Chaque pas sur le cercle = 1 note change.

1 pas : 6 notes communes, transition tres naturelle
2 pas : 5 notes communes, transition douce
3 pas : 4 notes communes, transition audible
6 pas : triton, rupture maximale

Utilise un accord pivot (commun aux deux tonalites) pour moduler sans rupture.

HarmonyLab
Outil de theorie musicale et de production — usage offline, aucune connexion requise
HarmonyLab est un outil concu pour les producteurs de musique electronique (DnB, Neurofunk, Techno, Hi-Tech Minimal). Il couvre quatre domaines : theorie musicale, modulation harmonique, calculs studio synchronises au BPM, et transposition de samples. Tout fonctionne dans le navigateur, sans installation.
Gamme et Accords
Theorie musicale interactive
A quoi ca sert
Identifier les notes et accords d'une tonalite. Savoir quels accords sont compatibles entre eux dans une progression. Trouver les notes a utiliser en melodie sur un accord donne. Comprendre la fonction harmonique de chaque degre.
Comment l'utiliser
1. Selectionne ta tonique (la note racine de ton morceau) dans la grille en haut.
2. Selectionne le mode : Mineur Naturel pour du DnB sombre, Majeur pour quelque chose de lumineux, Dorien pour une couleur jazzy.
3. Le clavier colorie les notes : bleu = dans la gamme, jaune = accord selectionne, sombre = hors gamme.
4. Clique un accord dans le tableau pour le selectionner : le clavier se met a jour et le guide melodie apparait avec les notes classees par couleur harmonique.
Concepts cles
Accords diatoniques
Les 7 accords natifs de ta tonalite. Ils partagent toutes les memes notes, donc ils sont toujours compatibles entre eux. Base de toute progression.
Accords empruntes
Accords qui ne sont pas natifs de ta tonalite mais qui s'y integrent bien (mode parallele, mineur harmonique). Ils apportent une couleur inattendue sans quitter l'espace harmonique.
Tonique vs Fondamentale
La tonique est le centre harmonique du morceau (concept musical). La fondamentale est la frequence physique la plus basse d'un son, mesurable dans SPAN (concept acoustique). Les deux ne coincident que quand ta basse joue le I degre.
Cercle des Quintes
Navigation harmonique et modulation
A quoi ca sert
Visualiser les relations entre tonalites. Trouver vers quelle tonalite moduler sans rupture. Identifier les gammes relatives et paralleles. Trouver les accords pivot pour transitionner en douceur.
Comment l'utiliser
1. Clique n'importe quel segment du cercle pour naviguer vers cette tonalite (anneau exterieur = majeur, anneau interieur = mineur).
2. Le panel Modulations liste les tonalites voisines avec le nombre de notes communes et les notes qui changent.
3. Les Accords pivot en bas sont les accords communs aux tonalites a 1 quinte — utilise-les dans ta progression pour transitionner naturellement.
Regle pratique
Chaque pas sur le cercle = 1 seule note change. A 1 pas tu as 6 notes communes (transition tres naturelle). A 6 pas (triton) tu n'as qu'une note commune (rupture maximale). En DnB et Techno, les modulations les plus efficaces se font a 1 ou 2 pas, ou vers la relative majeure/mineure (0 note change, meme gamme, tonique differente).
BPM et Studio
Delay, Reverb, Compresseur, Saturation
A quoi ca sert
Calculer les timings d'effets synchronises a ton BPM. Avoir les bonnes valeurs de delay, reverb, attack et release en millisecondes pour ton tempo sans faire le calcul a la main.
Comment l'utiliser
1. Regle le BPM en haut — tout se recalcule automatiquement.
2. Pour le Delay : choisis la division rythmique souhaitee, regles le feedback, lis le nombre de repetitions audibles et le temps de decroissance total.
3. Pour la Reverb : lis les pre-delay et RT60 recommandes par type (Room, Hall, Plate...).
4. Pour le Compresseur : lis les valeurs en ms pour chaque subdivision, puis applique-les dans Pro-C 2 ou ton compresseur.
5. Pour la Saturation : choisis le type (Tape, Tube, Hard Clip...) et regle le drive.
Concepts cles
Feedback delay
Chaque repetition = signal x (feedback%). A 40% : signal original → 40% → 16% → 6.4%... Le calcul indique combien de repetitions restent audibles au-dessus de -60 dB et la duree totale de decroissance.
Pre-delay reverb
Silence entre la note directe et le debut de la queue de reverb. Typiquement 10-80ms. Au-dela de 100ms tu entends un echo, pas un pre-delay. Se cale sur 1/32 ou 1/16 en BPM sync.
RT60
Reverberation Time 60 dB = temps que met le son pour decroitre de 60 dB apres arret de la source. C'est la duree de la queue de reverb. Room : 0.3-0.8s. Hall : 1.5-3.5s. Plate : 0.8-2s.
Transposition
Calculateur de pitch shift pour samples
A quoi ca sert
Calculer exactement combien de demi-tons appliquer pour transponer un sample d'une note a une autre. Par exemple : tu as un sample de basse root C, tu veux l'utiliser dans un morceau en D — l'outil te donne +2 demi-tons, les valeurs en cents, et quel algorithme FL Studio utiliser selon le contenu.
Comment l'utiliser
1. Clique la note source (note fondamentale du sample tel qu'il est enregistre).
2. Clique la note cible (la note souhaitee).
3. Lis les resultats : demi-tons, cents, ratio de frequence, changement de vitesse sans formants.
4. Selectionne le type de contenu (Drums, Basse, Melodique, Polyphonique, Voix) pour obtenir la recommandation d'algorithme FL Studio adaptee.
5. Consulte le mapping des notes en bas : il montre ce que chaque note de ta gamme courante devient apres transposition.
Correction de formants — quand l'activer
1-2 demi-tons
Correction optionnelle. Sur un sample simple monophonique, Newtone sans formants donne un resultat propre.
3-5 demi-tons
Correction recommandee. Sans elle, le timbre change notablement (effet chipmunk vers le haut). Newtone : active Formant Correction. Edison : coche Preserve formants.
6 demi-tons et plus
Correction indispensable. Meme avec formants la qualite se degrade sur les grands shifts. Utilise Melodyne pour les samples polyphoniques ou vocaux.
